# Contributing to HivePostify

Thanks for helping. Most of our public repositories hold documentation, so the most useful contributions are corrections, clearer wording and answers we forgot to write.

## Before you start

- Look through the open issues in case someone has already raised it.
- For anything bigger than a small fix, open an issue first so we can agree on the direction.

## How to contribute

1. Fork the repository and make a branch with a clear name, like `fix-invoice-wording`.
2. Make your change.
3. Open a pull request and tell us what you changed and why.

## Writing style

We write for people.

- Plain English. Short sentences beat long ones.
- Use commas, colons and full stops instead of dashes.
- Say what is true today. If a number can change, such as a fee, say it is "currently" that value.
- No marketing claims that can't be checked.
- Sentence case for headings.
- Read it out loud. If it sounds odd, rewrite it.

## Pull request checklist

- [ ] The change matches how the platform works today
- [ ] Spelling and grammar are checked
- [ ] Links work
- [ ] The description explains the reason

## Conduct

By taking part, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
