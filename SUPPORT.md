# Getting support

| You need | Go here |
| :--- | :--- |
| Help with your account, payments or an invoice | [hivepostify.com/support](https://hivepostify.com/support) |
| A how-to answer | [Platform guide](https://hivepostify.com/guide) and the [documentation](https://github.com/HivePostifyPk/hivepostify-docs) |
| To report a mistake in the docs | Open an issue in the [docs repository](https://github.com/HivePostifyPk/hivepostify-docs/issues) |
| To report a security problem | Follow the [security policy](SECURITY.md). Please don't post it publicly |

GitHub issues are for documentation. Account and payment problems should go through the support page, where we can look at your account. Please never post passwords, wallet keys or private payment details in an issue.
